# Referee Report — Full Framework Review
**Induced Superfluid Cosmology: A Theoretical Framework for Emergent Gravity and Dark Matter (TRXT-Nullivance)**

Reviewer: lab referee role (PRD/JCAP standard). Date: 2026-07-09.
Inputs: mathematician audit (`audit_core_framework_20260709.md`), gate ledger (`results/logs/gate_ledger.md`), data confrontation (`results/logs/data_confrontation_20260709.md`), specs, manuscripts, code forensics.

## Summary of the claim

The framework asserts that (i) spacetime and gravity emerge from an NJL-type condensate of Planckian fermions (Sakharov-style induced gravity on an acoustic metric); (ii) Standard Model particles are topological excitations, with masses following m(p,q) = M*(1/p + 1/q) for torus winding numbers (p,q); (iii) dark-matter and dark-energy phenomenology (SPARC rotation curves, Bullet Cluster separation, relic abundance, H0/S8 tensions) follow from the same single action with parameters emerging rather than being tuned; (iv) the framework has passed a 6-gate validation ladder against real data.

## Findings

**F1 — MAJOR (mass law is statistically empty).** The headline result fails a null test: with the (p,q ≤ 200) lattice (1,246 modes in [50,200] GeV) and M* anchored to m_τ/α, random masses match as well as W/Z/Higgs (look-elsewhere-corrected p = 0.23/0.59/0.09; 52.5% of random masses match within 0.1%). The repo's own robustness report concedes a >100% random-match chance. Evidence: `results/logs/mc_null_test_20260709.log`, `results/logs/robustness_report_real_data.txt`.

**F2 — MAJOR (circularity in the relic "derivation").** `experiments/v14_phase_j/v14_j1_final_m_star_relic.py:72-81` computes the target cross-section *from* Planck's Ω_DM h² = 0.120, then reports sub-σ agreement with the same number as a parameter-free prediction. The file series `v14_j1_m_star_relic_derivation.py` → `refined` → `final` documents iteration toward the known answer. This pattern ("expert audit recovery" scripts J1–J9 produced in a single day, 2026-03-01, each landing on the desired resolution) indicates reverse-engineering, not derivation.

**F3 — MAJOR (validation suite cannot fail).** Per the gate ledger: NPL-G3 validates against data generated by the model itself (`v_obs = v_model + noise`); G5-BBN hardcodes Yp with the physics module absent and passes "By Design"; the suite prints "ALL 5 GATES OF DOOM SURVIVED" even when G4 fails in the same run; G0 does not compute its declared criterion. A gate system that cannot fail provides zero evidential weight (MASTER-PROTOCOL Articles II, V).

**F4 — MAJOR (stability proof covers the wrong branch).** Appendix X proves ghost-freedom and subluminality only for X > 0, but screening configurations have X < 0, where the same P(X) develops a ghost boundary and a superluminal window (mathematician audit Item 5). The theory's claimed G0 pass therefore has no proof behind it — directly relevant to GW170817-class constraints.

**F5 — MAJOR (the killer test has no evidence).** The Bullet Cluster gate — designated "The Killer" by the project's own protocol — currently has no runnable data in the repo (`data/raw/` lacks the FITS files); existing PASS figures are unreproducible artifacts from before restructuring. A framework replacing dark matter cannot cite an unrunnable Bullet Cluster test.

**F6 — MAJOR (internal story-switching).** The framework simultaneously (a) replaces dark matter with modified dynamics for Bullet/SPARC and (b) provides a thermal-relic dark particle ("dark tower") matching Ω_DM (F2). These are competing explanations of the same phenomenon; deploying whichever fits each dataset violates the project's own Anti-Frankenstein Law. The manuscript must commit: is Ω_c h² = 0.120 made of particles or of geometry?

**F7 — MINOR (fitted global scale at the threshold).** v17-G3 grid-fits universal a0 = 3550 on the full SPARC sample and lands at χ²_red = 4.9986 against a threshold of 5. Fit is legitimate methodology if declared as a fit; a "PASS without tuning" claim is not. Recommend a held-out split.

**F8 — MINOR (dimensional defects in foundational equations).** The mono-metric postulate as displayed is dimensionally ill-formed (vector added to rank-2 tensor); V ~ −|Φ|²ln|Φ|² lacks a reference scale (audit Items 3, spot-checks). These are fixable but sit in the framework's *defining* equations.

**F9 — QUERY (literature positioning).** The manuscripts do cite Khoury/Berezhiani superfluid DM and GW170817. However: what observable distinguishes TRXT-Nullivance from Berezhiani–Khoury superfluid DM and from standard induced-gravity programs? Absent F1's mass law (statistically empty) the referee cannot identify a unique falsifiable prediction. Provide one, with a number, before resubmission.

**F10 — QUERY (induced gravity magnitude).** No computation of the induced Newton constant (sign and magnitude) from the declared NJL parameters is exhibited anywhere. Sakharov-type constructions notoriously face the cosmological-constant problem (induced Λ ~ Λ_cutoff⁴); the L0 "computational cost" argument is currently prose, not a calculation.

## Reproduction result

PARTIAL. Gate scripts reran (see gate ledger): G1-spectrum, G4-v17 reproduce their claimed passes; G3-v17 reproduces only with the a0 fit; NPL-G4 FAILS (contradicting the suite's own banner); NPL-G3 and G5 passes are artifacts (F3). Mass-law "robustness" reproduces but is null-consistent (F1).

## Verdict: **REJECT** (as a validated physical theory; encourage resubmission as exploratory framework)

**Editor's sentence:** The manuscript's central quantitative claims are either statistically indistinguishable from chance (mass law), circular (relic abundance), or supported by a validation suite that cannot fail; the interesting theoretical skeleton (induced gravity from a fermionic condensate with topological excitations) is not yet accompanied by a single non-trivial, pre-registered, falsifiable prediction.

**Constructive path (what would change this verdict):**
1. One pre-registered prediction with a number (e.g. a fixed-(p,q) mass for an unmeasured state, or a specific SPARC held-out χ²).
2. The induced-G computation (F10) and the X < 0 stability analysis (F4).
3. A gate suite where every criterion is computed, thresholds are pre-declared, and failure is possible — starting with a real Bullet Cluster run (F5).
4. A single committed dark-matter story (F6).
