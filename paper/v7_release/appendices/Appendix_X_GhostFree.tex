\begin{equation}
    P_X + 2X P_{XX} > 0
\end{equation}
where $P_X = dP/dX$ and $P_{XX} = d^2P/dX^2$.

For TRXT: $P(X) = c_2 X + c_4 X^2$ with $c_2 = 1$ and $c_4 = M_*^{-4} > 0$. We have:
\begin{align}

    P_{XX} &= 2c_4 \\
    P_X + 2X P_{XX} &= c_2 + 2c_4 X + 4c_4 X = c_2 + 6c_4 X
\end{align}

For $c_2 > 0$, $c_4 > 0$, and $X > 0$: \textbf{This is always positive.}
